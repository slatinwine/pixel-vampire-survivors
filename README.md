# 像素吸血鬼幸存者 (Pixel Vampire Survivors)

单文件 HTML 像素生存游戏 —— 复古 480×270 低分辨率画布 + 手写逐像素点阵精灵。

**在线试玩**: https://slatinwine.github.io/pixel-vampire-survivors/

## 玩法
- WASD / 方向键移动（手机用左下虚拟方向键，支持八方向滑动换向）
- 武器全自动开火，吃宝石升级、三选一强化
- 存活 15:00 即胜利，之后可进无尽模式
- P 暂停 / M 静音（触屏设备用右上按钮）

## 特性
- 6 种可升级武器（魔法飞弹/飞斧/圣典/圣鞭/十字/大蒜圣域）+ 6 种被动
- 6 种敌人 + 定时 Boss「死亡收割者」+ 尸潮事件
- 芯片音效（WebAudio）、伤害飘字、屏幕震动、扫描线滤镜
- 零依赖，双击 index.html 即可离线游玩
